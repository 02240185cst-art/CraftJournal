Open CraftJournal.xcodeproj in Xcode (15 or later).
1. Select the CraftJournal target > Signing & Capabilities > choose your Team.
   If it complains, change the Bundle Identifier to something unique.
2. Pick a Simulator and Run (Cmd+R). Taking photos needs a real iPhone
   (Take Photo is greyed out in the Simulator).
Note: this project file was generated without Xcode and is untested.
